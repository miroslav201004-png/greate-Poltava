# 🏛️ Полтава: Духовна столиця та місто затишку

Ласкаво просимо до проєкту, присвяченого місту з неймовірною історією та особливим вайбом.

## ✨ Чим вражає Полтава?
* Кругла площа: Унікальний ансамбль у стилі класицизму, серце нашого міста.
* Біла альтанка: Місце з найкращим краєвидом на Поділ та Ворсклу.
* Полтавські галушки: Не просто їжа, а справжній гастрономічний символ.
* Краєзнавчий музей: Шедевр українського модерну, повз який неможливо пройти.

## 💻 Про розробника
Проєкт створено студентом ПКНГ (Полтавського фахового коледжу нафти і газу) в рамках вивчення веб-технологій та популяризації рідного краю.
